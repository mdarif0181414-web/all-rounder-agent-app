# All-Rounder Agent — Web App

A generalist autonomous AI agent (ReAct core + browser tools + long-term
memory) with a faceless-video production studio, in one free web app.

- **Chat** — answers from long-term memory, with sources cited.
- **Production Studio** — give a brief; get research, script, shot list,
  SEO package and a report, with a built-in contract self-check.
- **Memory** — see and search what the agent remembers.

Deploy on Streamlit Cloud: main file `stage7/app.py`.
Secret required: `GEMINI_API_KEY` (Google AI Studio free key).
